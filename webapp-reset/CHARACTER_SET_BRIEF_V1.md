# Character Set Brief — for Humaaans / Blush export

**For the parallel illustration work (path A).** Build these **4 role characters** so they're consistent, culturally authentic, and do their jobs. Supports the [Illustration Plan](ILLUSTRATION_PLAN_AUTH_ONBOARDING_V1.md).

## Global rules (apply to all four)

- **One builder, one style** for the whole set so they read as a family. **Recommend Humaaans** (explicitly supports farmers/buyers/students/lecturers; consistent style). Blush only if you prefer its look — but don't mix.
- **Kenyan authenticity, with dignity:** appropriate skin tones; locally-appropriate, practical dress; confident/warm posture. **Not** Western-office defaults, **not** stereotyped or "needy" framing. These are capable people.
- **Export:** **SVG, transparent background**, full body or 3/4, each character roughly the same height/crop so they align.
- **Colour-neutral-ish:** keep palettes simple; we'll recolour to the brand at the Design System gate. Avoid baked-in purple/blue.
- **Naming:** `char-farmer.svg`, `char-buyer.svg`, `char-student.svg`, `char-lecturer.svg` — drop into the Figma file (page "App — Lo-Fi Wireframes") or share them.

## The four characters

| Character | Who / context | Pose / action (the job) | Used on |
|---|---|---|---|
| **Farmer** | Kenyan smallholder farmer | Standing, confident, **holding/near produce** (e.g. a crate of tomatoes) — a producer with something to sell | ON-01 Welcome, ON-02 Intent "sell", ON-04 Role confirm, farmer first-run |
| **Buyer** | Kenyan buyer/trader | Considered, **evaluating** — holding a phone or a basket, mid-decision (sourcing, not impulse) | ON-02 Intent "buy", buyer first-run |
| **Student** | Kenyan CS student (younger) | **At a laptop**, focused/aspirational — building real work | ON-02 Intent "build a portfolio", education hub, student first-run |
| **Lecturer** | Kenyan academic | Professional, **reviewing** — with a document/tablet, considered | ON-02 Intent "review work", lecturer first-run |

## Optional (later, lower priority)

- A **"farmer + student together"** pairing for the Welcome screen (belonging). Can be composed from the two above.
- A small **cooperative/community** scene (Open Doodles) for group-orders / NGO contexts.
