# Modern Web App Research

**Reset deliverable 14** (Gate 4). The directive's filter: **separate "design that looks impressive" from "design that helps users succeed."** We take the durable, success-driving patterns and ignore award-bait.

## Patterns that help users succeed (take these)

1. **Role-based adaptive shells.** Multi-role platforms succeed when each role sees a navigation/home tuned to *their* job (Gate 1: five roles, very different goals). One generic shell for all underserves everyone.
2. **Progressive disclosure.** Reveal complexity on demand — *glance → detail*. This single pattern reconciles the platform's core tension: **simplicity for low-literacy farmers AND density for lecturers/admins** on the same system. Central to the Trust Score (tier at a glance, breakdown on demand) and density strategy.
3. **Visible system status & immediate feedback** (Nielsen heuristic #1). The platform's highest-anxiety moments — payment, submission, verification — demand unambiguous, immediate status. This is a retention/trust feature, not a nicety.
4. **Forgiving flows + first-class empty/loading/error/success states.** Long-term, daily-use products win on the *un-happy* paths, not the demo path. (The reset already mandates these states with illustration support.)
5. **Resilience & speed as features.** Content-first, fast, works on poor connections and resumes gracefully. For this audience that's the difference between use and abandonment — not a performance "nice-to-have."
6. **Quick actions / efficient interactions for power roles** (lecturer queue, admin triage) — keyboard paths, fast scanning, minimal clicks per decision.

## What we reject (impressive ≠ helpful)

- Trend-chasing (Dribbble/Awwwards aesthetics, hype patterns) — explicitly forbidden by the directive.
- Motion/visual spectacle that costs performance (fatal on weak devices).
- "Engagement" dark patterns — actively destructive to a trust platform (see Anti-Patterns, 15).
- Novelty navigation that breaks learned mental models for low-digital-literacy users.

## The synthesis

For *this* platform, "modern" = **clear, fast, resilient, role-aware, status-honest, and progressively disclosed** — not flashy. Modernity is felt as *reliability and clarity*, which is also exactly what builds trust.
